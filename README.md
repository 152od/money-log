# 💰 나만의 용돈 관리장

0원에서 시작해 날짜별로 수입과 지출을 기록하고, 일주일 지출이 10만 원을 넘으면 실시간으로 알려주는 웹 프로그램입니다.

## 주요 기능
- **0원 시작 잔액 관리:** 용돈(수입)과 지출을 추가할 때마다 총 수입, 일주일 총 지출, 남은 잔액이 실시간으로 계산됩니다.
- **10만 원 지출 경고 배너:** 지출을 입력할 때 일주일 누적 지출이 10만 원 이상이 되면 상단 배너가 경고 상태로 바뀝니다.
- **날짜별 내역 및 편의 기능:** 날짜(YYYY-MM-DD)별 입출금 내역 확인, 빠른 금액 버튼(+1천원~+5만원), 개별 삭제 및 전체 초기화가 가능합니다.

## 사용 방법
1. 날짜와 금액을 입력하거나 빠른 금액 버튼을 누릅니다.
2. **용돈(수입) 추가** 또는 **지출 금액 추가** 버튼을 누릅니다.
3. 상단 요약 카드와 경고 배너, 아래 입출금 내역에서 결과를 확인합니다.
